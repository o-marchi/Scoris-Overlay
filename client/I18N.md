# Internationalization (i18n) Guide

SCORIS supports multiple languages using **vue-i18n v11**. Currently supports:
- 🇺🇸 **English** (`en`)
- 🇧🇷 **Português (Brasil)** (`pt-BR`)

## How It Works

### Automatic Language Detection

The app automatically detects the user's preferred language in this order:
1. **localStorage** - If user previously selected a language
2. **Browser language** - Detects `pt` for Portuguese, defaults to English
3. **Fallback** - English is used if no match

### Language Persistence

When a user switches language, the preference is saved to `localStorage` and will be remembered on future visits.

## Using Translations in Components

### Setup in Script

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n';

const { t } = useI18n();
</script>
```

### Using in Templates

```vue
<template>
  <!-- Simple translation -->
  <h1>{{ t('nav.home') }}</h1>

  <!-- Translation with interpolation -->
  <button>{{ t('auth.signInWith', { provider: t('auth.discord') }) }}</button>

  <!-- Nested translations -->
  <p>{{ t('home.features.tournamentManagement.title') }}</p>
</template>
```

## Translation File Structure

Translation files are located in `/src/locales/`:

```
src/locales/
├── en.ts       # English translations
└── pt-BR.ts    # Brazilian Portuguese translations
```

### Example Translation Structure

```typescript
// en.ts
export default {
  nav: {
    home: 'Home',
    tournaments: 'Tournaments',
  },
  auth: {
    login: 'Login',
    signInWith: 'Sign In with {provider}',
  },
};
```

```typescript
// pt-BR.ts
export default {
  nav: {
    home: 'Início',
    tournaments: 'Torneios',
  },
  auth: {
    login: 'Entrar',
    signInWith: 'Entrar com {provider}',
  },
};
```

## Adding New Translations

### 1. Add to Translation Files

Add the same key to both `en.ts` and `pt-BR.ts`:

```typescript
// en.ts
export default {
  myFeature: {
    title: 'My Feature Title',
    description: 'Feature description',
  },
};

// pt-BR.ts
export default {
  myFeature: {
    title: 'Título da Minha Funcionalidade',
    description: 'Descrição da funcionalidade',
  },
};
```

### 2. Use in Component

```vue
<template>
  <h2>{{ t('myFeature.title') }}</h2>
  <p>{{ t('myFeature.description') }}</p>
</template>
```

## Translation Patterns

### Simple Text

```typescript
home: 'Home'
```

```vue
{{ t('home') }}
```

### Interpolation (Variables)

```typescript
greeting: 'Hello {name}!'
```

```vue
{{ t('greeting', { name: userName }) }}
```

### Pluralization

```typescript
items: 'no items | one item | {count} items'
```

```vue
{{ t('items', count) }}
```

### Nested Objects

```typescript
user: {
  profile: {
    name: 'Name',
    email: 'Email',
  }
}
```

```vue
{{ t('user.profile.name') }}
```

## Best Practices

1. **Always add to both language files** - Maintain parity between English and Portuguese
2. **Use descriptive keys** - `home.features.tournamentManagement.title` not `hfTmT`
3. **Group related translations** - Keep navigation together, auth together, etc.
4. **Test in both languages** - Switch languages to verify text fits in UI
5. **Use placeholders for dynamic content** - `'Hello {name}'` instead of string concatenation

## Testing Translations

### Manual Testing

1. Click the language switcher in the header (🇺🇸 EN or 🇧🇷 PT)
2. Verify all translated text updates immediately
3. Check that the selection persists on page refresh

### Common Issues

**Missing translation:**
- Error: `[intlify] Not found 'key.name' key in 'en' locale messages.`
- Fix: Add the missing key to `en.ts` and `pt-BR.ts`

**Wrong interpolation:**
- Text shows: `Hello {name}!` (with literal `{name}`)
- Fix: Pass variables: `t('greeting', { name: 'John' })`

## Adding More Languages

To add a new language (e.g., Spanish):

1. **Create locale file**
   ```bash
   touch src/locales/es.ts
   ```

2. **Add translations**
   ```typescript
   // es.ts
   export default {
     nav: {
       home: 'Inicio',
       // ...
     },
   };
   ```

3. **Register in i18n plugin**
   ```typescript
   // src/plugins/i18n.ts
   import es from '@/locales/es';

   messages: {
     en,
     'pt-BR': ptBR,
     es,  // Add here
   }
   ```

4. **Add to language switcher**
   ```typescript
   // LanguageSwitcher.vue
   const languages = [
     { code: 'en', name: 'English', flag: '🇺🇸' },
     { code: 'pt-BR', name: 'Português (BR)', flag: '🇧🇷' },
     { code: 'es', name: 'Español', flag: '🇪🇸' },
   ];
   ```

## Files Reference

- **Plugin:** `/src/plugins/i18n.ts` - i18n configuration
- **Locales:** `/src/locales/` - Translation files
- **Switcher:** `/src/components/LanguageSwitcher.vue` - Language selector UI
- **Integration:** `/src/main.ts` - App-level registration
